# aemet-mcp v0.1.2 🌦️

Mejora incremental sobre la [v0.1.1](./v0.1.1.md).

## ✨ Novedades

- **Racha máxima de viento en la predicción diaria**: `prediccion_diaria` muestra
  ahora la racha (km/h) junto al viento, cuando AEMET la proporciona.

  ```
  domingo 19/07
    Máx 36 °C / Mín 22 °C  |  Cielo: Poco nuboso  |  Prob. precip.: 0%  |  Viento: SO 15 km/h (racha 30 km/h)  |  Humedad: 70 % / 20 %
  ```

## 🔧 Interno

- Primera versión publicada **con provenance** mediante Trusted Publishing (OIDC).
  La [v0.1.1](./v0.1.1.md) se publicó por OIDC pero sin atestación (faltaba el flag
  `--provenance`, ya corregido).

## 📦 Instalación

```json
{
  "mcpServers": {
    "aemet": {
      "command": "npx",
      "args": ["-y", "@rldona/aemet-mcp"],
      "env": { "AEMET_API_KEY": "TU_KEY" }
    }
  }
}
```
