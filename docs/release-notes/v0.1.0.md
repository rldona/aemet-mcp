# aemet-mcp v0.1.0 🌦️

Primera versión pública de **aemet-mcp**, un servidor [MCP](https://modelcontextprotocol.io)
que da a Claude Desktop, Cursor y cualquier cliente MCP acceso al **tiempo oficial
de España** a través de la API pública [OpenData de AEMET](https://opendata.aemet.es/).

Se instala y arranca con un solo `npx`, sin backend propio.

```json
{
  "mcpServers": {
    "aemet": {
      "command": "npx",
      "args": ["-y", "@rldona/aemet-mcp"],
      "env": { "AEMET_API_KEY": "TU_KEY" }
    }
  }
}
```

## ✨ Qué incluye

**5 herramientas MCP tipadas** (esquemas zod, salida en texto legible):

| Herramienta            | Para qué sirve |
|------------------------|----------------|
| `buscar_municipio`     | Resuelve el nombre de un municipio a su código INE (tolerante a acentos). |
| `prediccion_diaria`    | Predicción de 1-7 días: máx/mín, cielo, prob. de lluvia y viento. |
| `prediccion_horaria`   | Predicción hora a hora de hoy y mañana. |
| `observacion_estacion` | Última observación real de una estación meteorológica. |
| `avisos`               | Avisos meteorológicos vigentes por comunidad autónoma. |

## 🧱 Ingeniería destacable

- **Encapsula las tres rarezas de la API de AEMET**: el patrón de *dos pasos*
  (primero un sobre JSON, luego la descarga real), el encoding **ISO-8859-1**
  (latin1) y los avisos como **tar.gz de XML (CAP)** — todo resuelto sin
  dependencias pesadas (solo el SDK de MCP y zod; `fetch` nativo, `zlib` nativo,
  y parsers de tar/CAP propios).
- **8132 municipios** del padrón oficial del INE bundleados: resolver
  nombre → código sin llamadas extra.
- **Robustez**: mapeo de estados `401/404/429` a errores claros, reintentos con
  backoff ante `429` y fallos de red/`5xx` transitorios, y caché en memoria con TTL.
- **Honestidad de datos**: nada de mocks en producción. Si AEMET falla, el error
  se propaga tal cual, sin ocultarlo tras valores por defecto.

## ✅ Verificado contra la API real

Las 5 herramientas se probaron end-to-end por el protocolo MCP contra la API de
AEMET (predicción de Madrid, observación de Retiro, avisos de calor de Andalucía,
etc.). La suite incluye tests de integración reales (guardados por `AEMET_API_KEY`)
además de 36 unitarios con `fetch` mockeado.

## 🐛 Un bug real que la verificación cazó

El mapa de códigos de área de las comunidades autónomas para los avisos **no sigue
el orden intuitivo**: van en orden alfabético y el código 65 es **Canarias** (no
Cantabria) y el 78 es **Ceuta** (no Canarias). Se detectó porque "Cantabria"
devolvía zonas de Gran Canaria, y se corrigió verificando código por código contra
la API. Hay test de regresión.

## 📋 Requisitos

- Node.js ≥ 18
- API key gratuita de AEMET OpenData
  (<https://opendata.aemet.es/centrodedescargas/inicio> → "Solicitar API Key").
