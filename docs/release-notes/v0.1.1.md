# aemet-mcp v0.1.1 🌦️

Versión de mejora incremental sobre la [v0.1.0](./v0.1.0.md).

## ✨ Novedades

- **Humedad relativa en la predicción diaria**: `prediccion_diaria` ahora muestra
  la humedad máxima y mínima de cada día (AEMET ya la proporcionaba y no se
  mostraba).

  ```
  domingo 19/07
    Máx 36 °C / Mín 22 °C  |  Cielo: Poco nuboso  |  Prob. precip.: 0%  |  Viento: SO 15 km/h  |  Humedad: 70 % / 20 %
  ```

## 🔧 Interno

- Primera publicación mediante **Trusted Publishing (OIDC)** desde GitHub Actions:
  sin `NPM_TOKEN`, con provenance automática y publicación directa (sin staging).
  Ver [ADR-0011](../adr/0011-trusted-publishing-oidc.md) y la
  [guía de publicación](../publishing.md).

## 📦 Instalación

```json
{
  "mcpServers": {
    "aemet": {
      "command": "npx",
      "args": ["-y", "@rldona/aemet-mcp"],
      "env": { "AEMET_API_KEY": "TU_KEY" }
    }
  }
}
```
